## 全部功能

### 📝 写作 & 编辑

| 功能 | 说明 |
|------|------|
| **双编辑器** | 纯文本（Markdown）/ 富文本（加粗/标题/图片/链接）自由切换 |
| **全文搜索替换** | 跨章节全局搜索，黄色高亮，逐条/全部替换，自动更新字数 |
| **语音输入** | 中文语音转文字，支持标点识别 |
| **自动保存** | 1.5秒延迟防抖 + 退出强制保存，绝不丢稿 |
| **历史快照** | 每3分钟自动快照，保留最近20个版本 |
| **50步撤销** | 跨保存周期的操作历史栈 |
| **字数统计** | 实时字数 + 30天柱状图 + 连续打卡 + 每日目标进度条 |
| **章节数超限** | 超1万字黄色警告，超1万5千字建议拆章 |

### 🤖 AI 写作助手

#### AI 对话（主Agent调度）
- **主Agent** (WorkspaceAgent)：理解需求→拆解任务→调用30+工具→委派子Agent
- **6 个子Agent**：大纲生成器 / 角色生成器 / 爽点检查 / 水文检测 / 爆款标题 / 中文去AI味
- **子Agent多轮推敲**：最多3轮迭代，收敛后输出最优结果
- **模糊匹配**：说"帮我生成大纲"→自动匹配大纲生成器，支持中文名/ID/关键词
- **联网搜索**：AI 直接调 web_search 查资料，结果可一键保存到资料库
- **选择卡片**：模糊需求→弹出预设选项，30秒冷却防骚扰
- **深度思考折叠**：AI 思考过程可展开查看/复制
- 多会话管理，历史记录保存到 SQLite

#### 编辑器内 AI 操作
- **专注模式**：一键隐藏所有面板，全屏码字，长按退出
- **崩溃恢复**：自动保存到临时文件，闪退后弹窗询问恢复
- 长按选中文字 → **润色 / 扩写 / 续写 / 联网查证**

#### 精修与审查
- **一键精修** — 8个维度：语病检查 / 节奏分析 / 文风统一 / 冗余删除 / 对话优化 / 描写增强 / 钩子检测 / 战力一致性
- **全文审查** — 设定冲突 / 战力一致性 / 伏笔追踪 / 角色一致性
- **爽点密度报告** — 分析每章爽点分布
- **水文检测** — 检测凑字数、重复描写
- **爆款标题生成** — AI 生成多个候选标题

#### 模型配置
- **厂商预设** — OpenAI / Anthropic / DeepSeek / 智谱AI / 通义千问 / Moonshot 等一键填入
- **获取模型列表** — 填 Key 后自动拉取可用模型列表
- **测试连接** — 绿灯验证，延迟显示
- **编辑/删除** — 已配置模型可随时修改或删除
- **25个写作风格预设** — 都市/玄幻/穿越/悬疑/女频全覆盖

## 🏗️ 技术架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                      用 户 界 面 层                                 │
│  MainShell (侧边栏FileTreeView + AiChatPage + 编辑器)              │
└──────────────────────────┬──────────────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────────────┐
│                    主 Agent (Main Orchestrator)                     │
│            WorkspaceAgent.chat() — 30+工具+子Agent调度              │
│                                                                     │
│  用户输入 → AI判断 → 调工具/委派子Agent → 执行 → 结果回传 → 回复  │
└──────────────────────┬──────────────────────────────────────────────┘
       ┌───────────────┼───────────────┐
       ▼               ▼               ▼
┌──────────────┐ ┌────────────┐ ┌──────────────┐
│ 子Agent x6   │ │ 工作流x4   │ │ 内置工具30+  │
│ 大纲/角色    │ │ 章节检查   │ │ 读/写/编辑   │
│ 爽点/水文    │ │ 全文审查   │ │ 分析/联网    │
│ 标题/去AI味  │ │ 大纲刷新   │ │ 配置/项目    │
└──────────────┘ └────────────┘ └──────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────────────┐
│                 数据存储层（100%本地）                               │
│  SQLite: 作品/章节/卷/统计  |  文件系统: .md/JSON/记忆             │
│  Secure Storage: API Keys  |  公共目录: NovelIDE/ (卸载不丢)       │
└─────────────────────────────────────────────────────────────────────┘
```

| 层级 | 技术 |
|------|------|
| **框架** | Flutter 3.32+ / Dart 3.8+ |
| **UI** | Material 3 + Riverpod 状态管理 |
| **编辑器** | TextField（纯文本）+ WebView（富文本） |
| **AI 调度** | WorkspaceAgent（主Agent）+ 6个子Agent |
| **数据库** | SQLite (sqflite) + Hive |
| **网络** | Dio（兼容 OpenAI / Anthropic / DeepSeek 等全系厂商） |
| **安全** | flutter_secure_storage（Android Keystore / iOS Keychain） |
| **语音** | 原生 TTS + STT（MethodChannel） |

## 🛠️ 快速开始

### Android

```bash
git clone https://github.com/qq1375828505/novelIDE.git
cd novelIDE
flutter pub get
dart run build_runner build --delete-conflicting-outputs  # 首次必须
flutter run
```

### Windows

```bash
cd "win版/novel-ide-windows"
npm install
npm run dev
```
